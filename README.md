Chương trình tinyShell

Yêu cầu hệ thống:
    1) gcc hỗ trợ C++ 20/n
    2) Linux distros/n
    3) cmake/n

Cài đặt chương trình:
    1) git clone https://github.com/alpine1808/tinyShell.git/n
    2) cd tinyShell/n
    3) mkdir build && cd build/n
    4) cmake ../n
    5) make/n
    6) ./tinyShell/n

Bắt đầu với help để biết thêm chi tiết.
