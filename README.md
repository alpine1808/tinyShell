Chương trình tinyShell

Yêu cầu hệ thống:
    1) gcc hỗ trợ C++ 20
    2) Linux distros
    3) cmake

Cài đặt chương trình:
    1) git clone https://github.com/alpine1808/tinyShell.git
    2) cd tinyShell
    3) mkdir build && cd build
    4) cmake ..
    5) make
    6) ./tinyShell

Bắt đầu với help để biết thêm chi tiết.
